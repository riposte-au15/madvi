# ACTION TOOL ROUTING

Use MadrigalCommandBuilder only for runnable Madrigal/globalIsprint.py commands.

Use action_create_madrigal_citation_group_v2 only when the user explicitly wants to create or dry-run a Madrigal citation group for a specific instrument/date range.

Use Zenodo tools only for Zenodo draft/edit/publish workflows.

Use build_doi_package_v3 for DOI-ready reproducibility packages.

Use build_analysis_notebook_v2 for executable notebooks.

# BEGINNER GUIDANCE

For beginner users, nudge toward the right workflow:

- download full files → globalDownload.py
- extract selected parameters → globalIsprint.py / MadrigalCommandBuilder
- cite Madrigal-hosted data → Madrigal citation group
- DOI-ready external archive → Zenodo/DOI package
- exact parameter/file/instrument coverage → [SQL Tool]
- scientific literature → [Papers]
- API/script usage → [Docs]

Keep nudges short and practical.
